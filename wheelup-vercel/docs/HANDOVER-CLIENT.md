# WheelsUp Sales システム 引き継ぎ資料（クライアント向け）

作成日：2026年5月
対象読者：クライアント企業の経営・運用責任者

---

## 1. このシステムでできること

御社の人材紹介事業を支援する社内ツールです。
2つの機能を1つのシステムにまとめています。

### 機能1：面談フィードバック
　キャリアコンサルタントの面談議事録を投入すると、AI が自動で採点・コメントを返します。
　リーダー（小林さん）の過去の面談を教師データとして使い、メンバーの面談を「リーダーならどう話したか」という観点で評価します。

　- 5つの観点で10点満点採点：ニーズ深掘り／提案力／信頼構築／前進／情報収集
　- 議事録の中から「ここが良かった／弱かった」の根拠を引用
　- 次回の面談に活かせる具体的な改善提案
　- メンバー個人の成長を時系列グラフで可視化
　- 採点と実成果（次回予約／応募／採用）の相関分析（リーダー専用）

### 機能2：RA新規開拓
　建築設備・施設管理・ゼネコン領域の企業246社を対象に、求人ページを自動巡回し、登録候補者4名とのマッチングを毎日更新します。

　- 求人ページの毎日自動クロール
　- 候補者プロフィールと求人を AI でマッチング評価（◎○△×）
　- 優先順位付きの「今日アプローチすべきリスト」を自動生成
　- 新規ターゲット企業の AI による発掘提案
　- 送信履歴・商談履歴の記録

## 2. 利用ユーザー

現状5名想定です。

- 小林さん（リーダー）：全機能利用可能、全メンバーの面談閲覧可
- 西村さん、辻内さん、安藤さん、村上さん：自分の面談のみ閲覧・採点

メンバーの追加・変更はソースコードを書き換える必要があります（簡易実装のため）。

---

## 3. 月額コスト

通常運用での想定コストです。

- Vercel（システム稼働基盤）：月額20ドル前後
　※ 現状は無料プランですが、複数人で開発・運用する場合は有料プラン必須
- Supabase（データベース）：無料枠で運用可能
- Google Gemini（AI 採点）：無料枠で運用可能
- GitHub（ソースコード管理）：無料
- ドメイン（任意）：年額1,000～3,000円程度

合計の目安：月額 0～20ドル（約3,000円以内）

利用者が増えたり面談数が大幅に増える場合は、有料プランに切り替える必要が出てきます。

## 4. 引き継ぎ時にお願いしたいこと

円滑な運用のため、以下の所有権移管が必要です。

### 必須

1. Vercel プロジェクトの移管
　現在は開発担当者の個人アカウント（無料プラン）に紐づいています。
　御社アカウントへの移管と有料プラン化を推奨します。
　無料プランのままだと複数人での開発ができません。

2. Supabase プロジェクトの移管
　現在のデータは開発担当者の個人アカウントに紐づいています。
　御社アカウントへの移管をお願いします。

3. Google Gemini API キーの再発行
　現在は開発担当者の個人キーを使っています。
　御社で Google AI Studio から新規発行し、置き換えてください。

### 推奨

4. 独自ドメインの設定（任意）
　現状は `*.vercel.app` の標準ドメインを使用しています。
　社内案内のしやすさを考えると、御社ドメインを当てることを推奨します。

## 5. データの安全性について

ユーザーが誤って操作してもデータが消えない設計です。

- 議事録の削除：物理削除ではなく「ゴミ箱」状態（論理削除）。あとから復元可能。
- 採点結果の上書き：上書き前に必ず履歴を保存。過去のスコアはいつでも参照可能。
- AI へのデータ送信：議事録は Google Gemini に送信されますが、Google API ポリシーにより学習には使われません。

---

## 6. セキュリティについて

- ログインユーザー名はブラウザに保存され、その人として API を呼び出します（簡易認証）。
- データベース（Supabase）は外部からの直接アクセスを遮断しています（Row Level Security有効）。
- API キー類はサーバー側でのみ使用し、ブラウザには露出していません。
- AI への悪意ある指示混入を防ぐため、議事録は専用タグで囲んで送信しています。

将来的にユーザー数が増える場合は、メールアドレス＋パスワードによる本格的なログイン機能への移行を推奨します。

## 7. 日常運用で発生する作業

ほぼ手間はかかりません。以下の作業のみ想定されます。

- 議事録のテキストを投入する（録音 → 文字起こしは別ツール想定）
- AI 採点ボタンを押す（自動採点はあえてしていません。コスト管理のため）
- 面談結果（次回予約／応募／採用）を記録する
- リーダーがダッシュボードで全体傾向を確認する

RA 開拓は毎日自動巡回するため、人手作業は「結果を見てアプローチする」だけです。

## 8. トラブル時の対応窓口

引き継ぎ後の対応体制は別途ご相談させてください。
よくあるトラブルと対応の目安：

- 「サイトが開かない」→ Vercel の稼働状況を確認
- 「AI 採点が失敗する」→ Gemini の利用枠を確認、無料枠超過時は有料プラン検討
- 「データが消えた気がする」→ 履歴テーブルから復元可能、データは消えていません
- 「ユーザーを追加したい」→ 開発担当者によるソースコード修正が必要
